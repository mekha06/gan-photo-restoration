GAN-Based Photo Restoration

A deep learning project that restores old and damaged photographs using a Pix2Pix GAN implemented in PyTorch.

Features
Restore scratches, blur, noise, and faded regions
Generate paired training data with artificial damage
Pix2Pix GAN with U-Net Generator and PatchGAN Discriminator
Evaluate results using PSNR and SSIM
Streamlit-based web interface for inference
